Description

DriftStuntingIndonesia is a server community of Grand Theft Auto San Andreas Multiplayer (Online), This is a gamemodes from this server you can use this for build an server in sa-mp, don’t remove my credits

Features

  • Teleports
  • Admin System
  • House system
  • Banking System
  • Christmas (December Only)
  • Custom Maps
  • Skinchanger
  • Weapon
  • VIP System

Plugins

  • Whirlpool
  • sscanf
  • audio
  • socket
  • irc
